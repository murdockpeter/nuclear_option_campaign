Authoring workflow

From intent
to mission.

The generator turns a campaign idea into a structured opening state through three focused workspaces. Every choice feeds the export model.

PHASE 01

Campaign setup

Set the strategic frame: where the fight begins, who owns what, and what the first operation must accomplish.

  • Map, factions & starting airfield
  • Rank, cash & reserve airframes
  • Time, weather & respawn rules
  • Manual location ownership
PHASE 02

Configure locations

Build the operational layer by binding named map points to exact in-game coordinates.

  • Click-to-capture map pixels
  • World X / Z coordinate mapping
  • Notes & ownership metadata
  • Immediate visual verification
PHASE 03

Advanced targets

Compose the objective package and tune how intensely the wider theater pushes back.

  • SAM, armor, artillery & factories
  • Patrol, convoy & front-line density
  • Air patrol count and radius
  • Controlled randomization

System capabilities

More than
a randomizer.

The generator creates a deliberate, inspectable mission state—then preserves the campaign data needed to carry that world forward.

TPL
01 / AUTHOR

Reusable target templates

Build layouts from vehicles, aircraft, buildings, and relative X/Z offsets. Import from saved template JSON or a Nuclear Option scenario, then reuse the package at any objective.

%
02 / WIN

Completion thresholds

Set how much of the designated target set must be destroyed—from a surgical 25% to total destruction.

OR
03 / STATE

Persistent ORBAT

Campaign state records factions, logistics, location control, objectives, units, buildings, and the mission export history.

AIR
04 / THREAT

Real airborne patrols

Enemy helicopters and fixed-wing patrols export as actual aircraft entries. Separate count and radius controls let you create a close rotary-wing screen and a wider fast-air response.

STM
05 / PATH

Steam discovery

Scans Steam library manifests for the local install, with manual path override and quick return to auto-detection.

PNG
06 / BRIEF

Briefing graphics

Exports a mission-ready PNG showing ownership, objective marker, authored terrain, and air patrol overlays.

CSV
07 / MAP

Location authoring

The Heartland CSV remains a transparent, editable source of truth for operational names and coordinates.
